Publish workflow

  1. Review and save your draft.
  2. Download the website content JSON file.
  3. Open the GitHub repository.
  4. Upload the downloaded file as site-content.json, replacing the existing file.
  5. Commit to main and wait for GitHub Pages deployment.

Publishing requires authorized GitHub repository access. The dashboard itself does not bypass GitHub permissions.
